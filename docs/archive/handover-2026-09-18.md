## 1. Project Overview

**HackMatch** - AI-powered teammate matching platform for hackathons.

> **"AI recommends. Humans decide."**

### Core Features
- Student/Professional identity verification
- Competition metadata extraction (Amazon Bedrock)
- Team creation with manual skill requirements
- AI-assisted candidate matching with explanations
- Join requests & invitations
- Eligibility system

### Product Decisions
| Decision | Choice | Reason |
|----------|--------|--------|

| Verification | College email (.edu, .ac.in) | Easy, automatic |

## 8. API Contracts (To Implement)

### Profile
```
POST /profiles - Create profile
GET /profiles/:id - Get profile
PUT /profiles/:id - Update profile
```

### Competition
```
POST /competitions - Create competition
POST /competitions/:id/analyze - AI extraction
```

### Team
```
POST /teams - Create team
GET /teams/:id - Get team
PUT /teams/:id - Update team (leader only)
GET /teams/:id/recommendations - AI recommendations
```

### Requests
```
POST /teams/:id/join-request - Request to join
POST /join-requests/:id/approve - Accept request
POST /join-requests/:id/reject - Reject request
POST /teams/:id/invite - Send invite
POST /invitations/:id/accept - Accept invite
POST /invitations/:id/decline - Decline invite
```
